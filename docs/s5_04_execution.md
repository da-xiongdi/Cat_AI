# S5-04 机器学习算法与优化

主计划登记章节。前置为 S5-01 协议冻结。本任务固定 F_base 与成员，和 S5-02 并行研究算法主效应。 [S5 总计划](s5_implementation_plan.md) · [协议](s5_01_execution.md)

## 01 估计器、依赖和运行协议

1. 在现有 `modeling/config.py`、`research_preflight.py` 和 `research_training.py` 扩展估计器构建与参数白名单。复用 Dummy、Ridge、Extra Trees，新增 `random_forest` 和一种批准的提升算法。固定模型种子、单线程和 CPU 设置，校验参数范围、类型、空值和未知键。
2. 核验 XGBoost 在项目 Windows/Python 3.14 和发布环境的轮子、许可、锁定依赖、CPU 可重放性及打包。失败时报告具体原因，在评分前确定一种 scikit-learn 提升算法备选或缩减范围。S5 记录其运行环境；历史 S4 包按原提交和锁定环境回归。
3. 复用 `preflight/train/train-batch/score`、现有分组随机划分、模型锁和包格式。只扩充新增候选所需契约，保持历史配置语义。先用合成材料验证新增算法的参数、训练、锁定、评分和重载，再在批准的数据分区上验证单条与混合批次、失败保留和重试。

## 02 固定参数比较

1. S5-E02 固定 F_base、共同资格、分组随机 80/20 及训练五折。Extra Trees 复用 S4 已冻结设置，100 树、最小叶 2、无深度上限、`max_features=1.0`、`n_jobs=1`、模型种子 42。RF 首轮建议用相同显式树数、容量和特征采样参数，保留 RF 自身的构树与 bootstrap 设置。提升算法预登记单套初始参数，Dummy/Ridge 固定作参照。 [S4 固定配置](../artifacts/reports/s4-03-frozen-20261120-v2/configs/EXP-01-42.json)
2. 用训练 OOF 比较固定参数算法。待评分对照臂提前登记，训练与留出报告均保留预测状态、诊断值、共同可用误差、DOI 分层和训练/预测成本。采用一致的 F_base 编码和适用域规则，按协议保留越界、非有限值或失败记录。

## 03 有限寻优与交互边界

1. 预登记默认方案及每个树算法最多 8 个候选参数组（含固定版本）。建议 ET/RF 只改树深、最小叶和特征采样，提升树只改浅深度、学习率和迭代数。复用现有候选清单枚举有限试验，冻结总预算、线程、超时和中止规则。早停如启用也仅访问对应训练侧材料。
2. 每个划分独立在训练五折内搜索。记录每个候选和折的参数、种子、所用 ID 散列、OOF 误差、覆盖、耗时及失败。按冻结规则选择后用该划分全训练集重拟合并锁定。固定参数与调参结果按相同成员和五折比较，留出成绩用于报告。预算耗尽按预登记回退处理。
3. E05 在 S5-05 执行预登记的有限组合。建议起步四组，即 F_base 和一个 F3 分别配 Extra Trees 与 RF。F3 选择和参数只以该划分训练侧规则为准，留出结果不得反馈给组合选择。
