# TheMeCat 数据库说明与使用指引（项目 V1.0）

> 项目：AI辅助 CO₂ 加氢制甲醇催化剂开发  
> 文档版本：v1.0（2026-11-10）  
> **当前数据库决策：仅采用 TheMeCat v1.0 作为项目现阶段的外部文献主数据源。** 其他文献数据库暂不纳入本阶段的数据导入和训练范围。  
> 本文档用途：提交 VS Code / Codex 项目，指导数据接入、质量审查、特征工程、基线模型与候选筛选。

## 0. 执行摘要

TheMeCat 是专门面向**热催化 CO₂/H₂ 制甲醇**的结构化公开文献数据集，由 Toldy 等发表在 *Scientific Data*（2026）。研究从 **44 篇原始文献**整理了 **822 条实验记录**，涵盖催化剂组成、部分结构表征、反应测试条件和性能指标。数据集的重点是**组成和性能数据的标准化及可追溯性**，并非详细的催化剂合成工艺数据库。

**本阶段能做的事**：规范导入数据、审查质量、构建基于组成与反应工况的性能预测模型、开展特征解释、在限定工况下虚拟筛选材料组成。

**本阶段不能据此直接做的事**：以 TheMeCat 原始字段训练“焙烧温度 / 还原时间 / 沉淀 pH → 性能”的模型，或输出经数据验证的完整催化剂合成工艺。今后若需要这一能力，必须另外补充实验或文献合成数据。

**验证状态说明**：已依据论文及 Zenodo 官方下载入口核对数据库说明和公开 CSV 表头；**尚未将完整 CSV 下载到本次本地环境并逐行跑完质量审计**。论文所述规模及字段与实际文件的内容、缺失比例和异常值，应由随附脚本在 VS Code 中复核后作为正式入库验收结果。

## 2. 收录范围及对比边界

### 2.1 纳入标准（论文规定）

1. **热催化、单程、填充床反应器**实验。
2. 以 **CO₂ 和 H₂ 为唯一反应物**；不收录 CO 作为额外反应物的研究。
3. 催化剂组成能够定量表示到元素或相应材料组分层级。
4. 保留各篇文献的多个实验条件数据点，而非仅采纳性能最佳值。

### 2.2 明确排除或未覆盖

- 吸附强化、等离子体辅助等具有额外过程强化机制的实验；不宜直接用于膜反应器或原位分离反应器的性能比较。
- 详细的**制备方法、前驱体、沉淀 pH、老化、干燥、焙烧、还原等工艺记录**。
- 大规模原位光谱或结构原始文件、完整活性位点机制描述符、稳定性 / 失活数据。
- 因文献报道不充分造成的部分性能、空速和物性缺失。

**材料覆盖**：以 Cu 基和 In₂O₃ 基为主，也包含 Pd、Pt、Ir、Au 及多种氧化物组合；材料体系并不均衡，罕见体系的数据不足以支持无约束外推。详见论文图 2、图 3。

## 3. 数据字段与单位（V1.0）

经官方 CSV 下载内容的**首行表头**核对，公开文件包含以下 **25 个字段**。字段名区分大小写，开发时应以**CSV实际表头**为准，不能仅依据论文 Table 1 生成字段映射。

### 3.1 文献和样品标识（4 列）

| 字段名 | 含义 | 处理建议 |
|---|---|---|
| `reference` | 文献来源（作者、年份） | 保存原文，不用作预测特征 |
| `doi_link` | 原始文献 DOI 链接 | 用于去重、文献分组验证和溯源 |
| `catalyst_name` | 文献使用的催化剂名称 | 与 DOI 组合建立样品候选标识 |
| `catalyst_composition_available` | 组成信息是否可得 | 实际 CSV 以文字形式呈现时再转换为布尔值 |

### 3.2 催化剂组成（10 列）

| 字段名 | 含义 | 数据类型 |
|---|---|---|
| `starting_material_active_1` | 活性组分 1 还原前/初始材料 | 化学式或缺失 |
| `active_comp_1` | 活性组分 1（约定状态） | 化学式或缺失 |
| `active_1_percent` | 活性组分 1 的摩尔百分比 | 数值，mol% |
| `starting_material_2` | 第二活性组分的还原前/初始材料 | 化学式或缺失 |
| `active_comp_2` | 活性组分 2 | 化学式或缺失 |
| `active_2_percent` | 活性组分 2 的摩尔百分比 | 数值，mol% |
| `support_comp_1` | 载体组分 1 | 化学式或缺失 |
| `support_1_percent` | 载体组分 1 的摩尔百分比 | 数值，mol% |
| `support_comp_2` | 载体组分 2 | 化学式或缺失 |
| `support_2_percent` | 载体组分 2 的摩尔百分比 | 数值，mol% |

**重要细节**：

- 数据集支持最多 **2 个 active + 2 个 support** 组分。这里的 `active/support` 角色来自原始文献的表述，**不等同于经过统一机理验证的活性位点定义**。
- 百分数是作者整理的**材料组分摩尔百分比**。如果要进一步转换为按元素计的摩尔分数或原子分数，应先解析化学式、正确处理计量数，**不能直接把四个百分数当成元素原子分数**。
- 文献中标称组成不一定经过 ICP/EDS 实测证实。后续应增加 `composition_evidence` 标志，但不可自行推断为实验测量。

### 3.3 结构表征（2 列）

| 字段名 | 含义 | 单位 |
|---|---|---|
| `catalyst_surface_area_m2_g` | 比表面积（BET） | m²/g |
| `mean_pore_diameter_nm` | 平均孔径 | nm |

这两个字段属于**制备后/测试前才可能获得的表征信息**，不应在“尚未合成的新配方直接推荐模型”中作为必需输入。可用于单独的**表征增强模型**。

### 3.4 反应测试工况（5 列）

| 字段名 | 含义 | 单位 |
|---|---|---|
| `temperature_k` | 反应温度 | K |
| `pressure_bar` | 反应压力 | bar |
| `pH2_pCO2_ratio` | H₂ 与 CO₂ 的分压比或摩尔流量比 | 无量纲 |
| `GHSV_nlph_gcat` | 按催化剂质量归一的入口气体体积流量 | **NL·h⁻¹·gcat⁻¹** |
| `catalyst_load_g` | 催化剂装填质量 | g |

**务必明确空速定义**：本数据集字段虽然命名 GHSV，但它采用的是**质量基准气体体积流量**，不是通常以床层体积定义的 `h⁻¹`。其 NL 参考状态：`T_ref = 293.15 K`、`P_ref = 101325 Pa`。没有床层密度或装填体积时，不能与 `h⁻¹` 的体积基 GHSV 直接互换。

论文图 4 及文字报告的总体范围：反应温度 **433–673 K**，压力 **0.4–60 bar**，质量基空速 **0.87–240 NL·h⁻¹·gcat⁻¹**。这些是论文描述的覆盖范围，**不代表每个材料体系在所有工况下都有足够样本**。

### 3.5 催化性能（4 列）

| 字段名 | 含义 | 单位 |
|---|---|---|
| `CO2_conversion` | CO₂ 转化率 X | % |
| `selectivity_CH3OH` | 甲醇选择性 S | % |
| `yield_CH3OH` | 甲醇收率 Y | % |
| `STY_g_per_gcath` | 甲醇时空收率 STY | gMeOH·gcat⁻¹·h⁻¹ |

**字段与论文表格差异**：论文 Table 1 另列 `comment_process` 与 `comment_catalyst` 两个备注字段，但公开 `TheMeCat_v1.csv` 的表头中**未出现这两个字段**；同时论文列名 `starting_material_active_2` 与 CSV 中的 `starting_material_2` 不一致。本项目始终以实际下载的 CSV 为准，若未来数据集升级，再通过显式适配器兼容。

## 4. 性能指标及可复算关系

请保留原始值，另建衍生列开展一致性校验。设 X、S、Y 单位均为 `%`：

```text
Y_percent_expected = X_percent * S_percent / 100
```

按文献采用的 H₂/CO₂ 输入、惰性气体不计入定义的质量基空速及参考状态，可计算：

```text
STY_expected [gMeOH / (gcat·h)]
  = GHSV_nlph_gcat [NL / (gcat·h)]
    × (1 / (1 + pH2_pCO2_ratio))
    × (yield_CH3OH / 100)
    × (32.04 [g/mol] / Vm_ref [L/mol])

Vm_ref = R * 293.15 K / 101325 Pa ≈ 24.05 L/mol
```

公式使用前必须确认该记录是否符合气体成分、流量参考状态及催化剂质量基准假设。不要盲目用复算值覆盖原始数据；记录 `reported` / `derived`、计算版本和相对偏差。原始论文指出，部分 STY 因流量或空速信息不足而**保留空值**，不能填成 0。

**特别注意**：`Y = X × S`，`STY` 又可由 `Y + GHSV + H₂/CO₂` 算得，因此四个目标并非完全独立。不能把 `yield_CH3OH` 或 `STY_g_per_gcath` 当作输入来预测 `CO2_conversion` 等前置性能，否则产生明显的目标泄漏。

## 6. 数据治理规则（必须实现）

| 项目 | 必做检查 | 处理原则 |
|---|---|---|
| 来源追溯 | DOI、reference、催化剂名 | 每条数据保留源文献和原始记录索引 |
| 原始文件 | MD5、版本、下载日期 | Raw 层不可覆盖、后续变更使用新版本 |
| 缺失值 | 数值列、组成列、性能列缺失率 | 缺失≠0；针对目标分别选择有效训练子集 |
| 数值范围 | X/S/Y 一般为 0–100%，T/P/GHSV为合理正数 | 标记异常，不自行修改真实文献数字 |
| 组成合计 | 四个组分的 mol% 合计 | 可计算时校验约为100%，容许舍入误差 |
| 公式一致性 | Y 对 X·S/100，STY 对流量等 | 输出偏差与异常记录清单，不覆盖原值 |
| 去重/同源 | DOI + catalyst_name + 工况 | 识别真正重复与同一样品不同工况测量 |
| 数据泄漏 | 同一 DOI / 相同催化剂样品跨训练集 | 优先按 DOI 分组评估，另提供样品级分组诊断 |
| 参考工况 | 操作变量取值位于训练支持范围 | 禁止在明显稀疏区域直接做高置信度排序 |

**不能将文献中的 822 条实验记录视为 822 种独立催化剂**。由于同一样品可能在多个工况下重复测试，随机按行分割会使同源样品同时进入训练集与测试集，从而高估泛化能力。

**建议划分原则**：第一阶段使用 `GroupKFold` 按 `doi_link` 分组（跨文献泛化）；可增加按 `doi_link + catalyst_name` 分组的辅助检验，但该键只是一种近似样品标识，不应自动视为真实实验批次 ID。对于文献数只有 44 的情形，应报告折间方差，并特别注意小样本材质类别的稳定性。

## 7. 初期机器学习使用方案

### 7.1 模型定位

**Model A：配方 / 工况 → 性能预测（优先开发）**

- 输入：active/support 组分、各材料 mol%、温度、压力、H₂/CO₂、质量基空速。
- 输出：CO₂ 转化率和甲醇选择性；可进一步计算收率及 STY。
- 模型：先用 Random Forest、CatBoost 或 XGBoost 建立单目标回归基线。
- 评价：MAE、RMSE、R²；训练集与 DOI 分组验证结果分开展示。
- 解释：Permutation Importance、SHAP（明确是模型相关性而非因果作用）。
- 不建议初期把 `catalyst_load_g` 作为最重要的材料性能描述符；它更多是试验设置/规模相关变量，应验证加入或去掉时是否带来虚假的相关性。

**Model B：表征增强预测（作为并行验证）**

- 输入：Model A 全部特征 + BET 比表面积 + 平均孔径。
- 由于表征缺失与新配方未知，这一模型仅在有表征结果的样本子集上训练，不用于替代未制备材料的直接筛选模型。
- 两模型性能比较必须使用可比的共同测试子集，否则难判断表征特征是否真的改善预测。

### 7.2 组成特征工程推荐顺序

1. V1 简单编码：`active_comp_1/2`、`support_comp_1/2` 类别编码 + 对应 mol%。
2. V1.1 稳健组成表征：解析化学式为元素计量，计算元素比例、原子量/电负性/电子结构等加权统计描述符；保留 active/support 角色以便比较。
3. V1.2 条件适用域：按材料体系、合成来源及工况密度标识低覆盖区域与外推风险。

**特征工程须避免**：未经验证把材料百分数当成质量百分比、使用性能衍生值作为输入、将缺失组成或表征值简单设为 0、把“active”角色强解释为唯一反应位点。

### 7.3 公平比较与虚拟筛选

模型预测可写成：

\[
\widehat{Y} = f(\mathrm{composition}, T, P, H_2/CO_2, GHSV)
\]

在比较候选催化剂时，**固定相同 T、P、H₂/CO₂ 和质量基空速**，仅改变合法的材料组成；输出预测性能、所属材料覆盖范围、最近邻训练样本距离（或其他适用域指标）和不确定性等级。

**明确区分**：同工况的**模型预测值**不等于经实验验证的“标准工况实测值”。这一模型本质上学习跨文献数据的统计规律，不能消除原论文的实验室差异、合成方式差异和表征缺失影响。模型推荐必须经过独立实验证实。

### 7.4 首轮候选推荐原则

- 不预先锁定唯一催化剂材料体系，但先在有充分训练数据支持的材料/组成区域筛选。
- 候选应具备可理解的化学组成、物质名称、可复现的元素/材料配比，避免仅输出“无意义的连续编码向量”。
- 优先选择多个组成有差异的候选，而非全部集中在同一区域。
- 目前实验平台每批最多测试 **4–6 个催化剂**；在获得实验接口之前，先形成候选排序和“待验证”清单，不标记为已成功验证。
- **关于合成方案**：TheMeCat 没有可靠的制备工艺字段。若要给实验室提供前驱体、焙烧或还原程序，应依据候选对应的原始文献另行整理，标注为“文献参考方法”，**不能写成模型从本数据库优化得到的工艺参数**。

## 8. 后续扩展接口（仅预留，不作为当前数据源）

为免未来新增自有催化剂实验数据时推翻架构，数据模型建议从一开始拆分：

```text
literature/source
     │
     ├── catalyst_formulation         # 组成、含量、材料角色
     ├── catalyst_sample              # 唯一样品 / 批次
     ├── synthesis_protocol           # 预留：前驱体、pH、干燥、焙烧、还原
     ├── characterization             # BET、孔结构、未来 XRD / XPS 等
     └── test_run                     # 反应条件、试验编号、性能测量
           └── performance
```

**本阶段 `synthesis_protocol` 仅建空表/定义 schema，不虚构填充**。后续可接入实验室的实际合成记录与性能测试。当前数据表可用 `source_type=literature_themecat`，并为文献行分配 `source_row_id`，从而避免将来自同一论文、同一配方的重复工况测量误认为不同样品。
