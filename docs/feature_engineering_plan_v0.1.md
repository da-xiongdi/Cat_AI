## 0. 实施顺序与实验预设

**S1：完善特征所需数据、导入、数据库和计算模块 → S2：建立模型与训练预测框架，同时交付用户参数入口 → S3：运行比较与验收。**

S1先准备近期确定使用的基础及最小物化特征：所需外部数据先导入治理、版本化入库，派生量由独立计算模块产生；不再把属性数据准备放到基础模型交付之后。S2依赖通过验收的特征输入，训练、保存、预测和参数入口一起建设。新增特征按相同顺序增量迭代，不要求先补齐所有远期描述符。

S1-B v4 保留 553 条，原 train/validation/历史 test 为 454/47/52 条，5,530 个派生值已持久化并完成重放。S2 交付第3.4节配置、F1/F2 训练、R2 比较框架及增强预测绑定。S3 在冻结输入上完成正式配对比较及端到端验收。见 [S2 任务分解](s2_implementation_plan.md)及 [S3 比较报告](s3_01_comparison.md)。

R1/R2现保留为基础/增强**实验预设，不再规定开发先后**；F0/F_cond/F_base/F1/F2是特征集；A/B1/B2是统一/单家族模型对照，区别于TheMeCat接入任务。下表说明实验输入和功能要求，不再代表两个顺序开发版本。

| 项目 | R1：基础对照预设 | R2：最小物化增强预设 |
|---|---|---|
| 数据 | 已冻结593条目标记录，按输入条件筛选 | 同一快照，另筛出最小物化属性完整的子集 |
| 材料表示 | 来源角色×物种×材料mol%；完整组成中缺席物种为0 | R1表示＋两项属性的来源角色均值、含量和差值 |
| 工况 | 温度、绝压、H₂/CO₂、质量归一反应物流量 | 与R1相同 |
| 模型 | 默认参数Dummy、Ridge、ExtraTrees | 同样模型和配对参数比较特征增益；参数入口另支持自定义运行 |
| 预测 | 输入组成和工况，加载绑定特征处理的模型 | 同一入口按特征版本调用属性表和规则 |
| 完成要求 | 筛选、训练、保存、加载、预测可重复运行 | 属性可溯源、同样本对照和增强预测可重复运行 |

本阶段不要求达到预设MAE/R²改善才算工程完成。R2即使无增益，也交付可运行管线和如实结果；是否采用增强模型由结果决定。默认基准固定参数，用户自定义运行单独保存配置和结果，不冒充固定基准。

## 1. 当前数据库与代码条件

已有SQLite治理库、原件哈希、修订、资格清单和不可覆盖快照。TheMeCat已有820条v2修订、609条curated，冻结593条CO₂转化率记录；来源接受不等于逐行原文核验，压力绝压仍为用户假设。

DOI分组共37篇论文，训练/验证/测试为493/47/53条，对应26/6/5组。已有`design-features-v1`、受限工况输入、训练词表，以及Dummy/Ridge/ExtraTrees、预处理、序列化和报告。依据见[当前进度](progress.md)、[数据字典](data_dictionary.md)、[特征代码](../src/catalyst_ai/features/design.py)和[基线代码](../src/catalyst_ai/modeling/baseline.py)。

2026-11-12只读检查现有快照和I3特征表得到：

- 593条记录对应141种组成签名，不代表593个独立配方，也不代表141个已确认独立样品。
- `material_family`来自催化剂名称，共195个不同原值，不能直接作为标准化家族标签。
- 当前角色只有`compound`和`support`：适配器将`active_comp_*`映射为前者、`support_comp_*`映射为后者，没有独立`promoter`标注。
- 现有I3表中组成均为available，四项核心工况均有值；装填量有缺失，四项计划合成字段全部缺失，本阶段不纳入。
- 实际物种包含`BaCO3`、`K2CO3`和`InNi3O0.5`等，不能仅考虑简单氧化物。

以上是派生表检查；实施时仍重新校验来源、单位、闭合和筛选条件，不预先承诺最终保留条数。**本阶段沿用来源角色，不重判真实活性位，不等待全家族分类、相类型或助剂重分类。**

## 2. 数据筛选与输入约定

### 2.1 来源与清单

催化剂事实从现有冻结快照、资格清单和DOI划分读取；所需外部属性先按第2.4节导入治理并版本化入库，再生成关联特征快照。不直接从raw/staged补入训练集，不覆盖原始记录或历史快照；通过可追溯追加方式完善数据库。新增运行级`selection.json`记录父快照/资格/划分ID、筛选规则版本、保留/排除记录ID及原因、各分区记录和论文数。它不替代治理资格，也不重新认定数据已核验。

筛选仅依据输入完整性、计量规则及预先固定的支持范围，不依据目标高低或模型误差。筛选后继承原DOI分区，不重新随机分配；分区或所需CV组数不足时停止相应评价，说明原因。

快照、资格清单、原件或划分的身份/哈希不一致时阻断整次运行，不能将完整性故障当作普通排除项继续训练。未见训练词表物种属于折内支持边界，不提前从全体数据删除；按第6节保留诊断和支持率。

### 2.2 组分缺失直接筛出

以下记录排除出相应版本输入，不插补组分身份或含量：

- 无法确认组成，缺少物种名称、已列组分含量或来源角色。
- 有孤立含量字段；不是明确的材料mol%；scope不是whole catalyst material。
- 含量非有限数、超出0–100%，或总和偏离100%超过现有容差0.5个百分点。
- 必填工况缺失、无效、单位或参考状态不符；目标不满足现有资格定义。

可选第二组分/第二载体槽位同时为空，不单独视为组成缺失，仍须组成声明及闭合检查通过。**完整、已确认的组成中没有某物种，编码为0；完整性不能确认则排除整条记录。** 不把全部空槽视为缺数据，不静默归一至100%。

R1允许身份和含量明确、但化学计量尚不支持的材料以物种身份进入。R2若任一正含量组分无法可靠展开或缺少必选属性，筛出该条R2输入并记录原因；不对剩余组分重新归一后冒充完整描述。

### 2.3 四项必填工况

| 字段 | 要求 |
|---|---|
| `temperature_k` | 温度K，有限且大于0 |
| `pressure_bar_abs` | 绝压bar(abs)，有限且大于0 |
| `h2_co2_ratio` | H₂/CO₂摩尔比，有限且大于0 |
| `reactants_flow_nl_g_h` | 按催化剂质量归一的反应物体积流量，有限且大于0 |

流量沿用现有代码的293.15 K、1.01325 bar(abs)、reactants_only和catalyst质量基准，不是床层体积GHSV。合法单位可通过已有标准化转换，不猜测缺失基准。

本阶段不使用装填量、历史/计划合成参数、BET、粒径、氧空位、时间、DOI、样品名或结果文本作为输入。

### 2.4 特征数据准备、导入与计算（S1）

先列特征需求清单，逐项标记`existing_field`（已有字段）、`imported_property`（需导入属性）、`computed_feature`（需计算），注明定义、单位、来源/算法版本、可用阶段、关联键及缺失/不支持策略。

| 对象 | 准备方式 | 存储与追溯 |
|---|---|---|
| 组成/四项工况 | 复用治理字段及快照，重查完整性、单位和计量 | record_id及snapshot_id关联，不补造缺失事实 |
| 电负性/共价半径 | 经核实CSV/JSON属性文件经专用适配器导入，先dry-run再导入 | 元素、属性定义/单位、来源/许可/版本、原件哈希、值/状态 |
| 物种中心计数 | 导入经确认的白名单映射 | 物种、中心计数、证据和映射版本，相同身份冲突阻断 |
| 角色均值/含量/差值 | 独立计算模块读取固定组成、映射和属性，按第4节公式计算 | 值、状态、计算版本、输入哈希及属性/映射引用，标为派生值 |
| 特征构建 | 按指定数据及属性版本生成受限输入和特征 | 版本化构建清单、特征快照及覆盖/排除清单，可查询可重算 |

复用SQLite及原件留存，增加最小属性来源、属性值、物种映射、特征构建及派生值的持久化能力。逻辑键包含元素/物种、属性定义、来源/属性版本；逐记录派生值关联record_id和父snapshot_id。具体表名和迁移脚本在实现中确定，提供旧库升级检查、幂等导入和冲突拒绝。YAML可作导入载体，正式使用引用已入库版本，不能仅把属性散落在配置文件。数据库保留未知/不适用状态，模型数组的0占位不得写回为物性事实。

导入负责格式、来源、单位、重复/冲突及持久化；计算负责确定公式、角色统计及特征版本。计算模块也支持新预测输入，不只给历史训练行手工补值。固定常数及不学习数据的计算可提前完成；词表、缩放等数据学习步骤仍仅在各训练折fit。

仅新增属性和派生特征不改原CO₂目标快照，不重新认定其已逐行核验。如需修订催化剂事实或新增性能记录，复用原修订、治理、资格和冻结链，生成新快照及相应划分。S1先交付近期所需导入、存储及计算能力和覆盖报告；不支持物种/属性按规则排除，不等待所有远期描述符。

### 2.5 S1-A补充：复合物种解析与来源歧义核查

本节要求已完成本轮S1-A验收，见[收尾说明](s1_a_acceptance.md)：39条登记证据不足，未生效事实更正；CoGaAlO4另1条保守隔离，联合支持553/593条。以下保留依据[ADR-019](decisions.md#adr-019复合物种核查与实施边界2026-11-13)的任务要求。化学式可解析、来源语义和正式资格分别判定；来源接受不等于逐行原文核验，不扩大为全库B3审计。

1. **记录级来源关联。** 以当前覆盖报告中含`InNi3O0.5`的39条记录为首批范围，先固定父快照及记录清单，再按DOI、原文样品名称聚合核查。重点查找`10.1016/j.fuel.2024.131111`及其他相关来源是否报告`InNi3C0.5`，核对样品与组成、角色、测试记录的对应关系；该线索不是已确认更正结论。聚合证据须能回落到每条记录和组分，不能仅凭同一字符串或论文中出现候选公式就批量替换。
2. **更正与解析分别版本化。** 更正映射至少保存父快照、record_id、组分角色及定位、原始字符串、候选/已确认修正公式、来源DOI、原文样品名、证据位置、证据原件哈希、审核状态及依据、修订版本。未确认候选不得生效。确认O→C等组成事实错误时，复用修订、治理、资格和冻结链生成新快照，并保存旧/新记录关联及DOI分区继承证据；不能仅通过描述符映射改变事实。纯中心计数映射更新则新增映射版本及构建，不修改目标快照。
3. **支持经确认的多中心计量。** 对`CoGaAlO4`等确定计量物种允许多个描述符中心，不强制唯一中心。完整元素计数与描述符中心计数分别保存，经审核登记后使用第4.2节统一权重。中心是描述符约定，不等同真实活性位，也不严格限于金属，须保留`SiO2→Si:1`等已有语义。
4. **保留完整物种身份与来源角色。** `BaCO3`等多原子阴离子化合物不拆成多个材料组分，碳酸根中的C/O不进入该物种的中心统计。化合物类别可作独立元数据，不能据此推断晶相、活性位或重分配reported_active/reported_support；本轮不将类别新增为F1/F2模型输入。
5. **区分确定小数与未确定组成。** 明确给出的有限正小数系数不自动拒绝；含x、δ等未定参数、来源冲突或组分未确定的物种继续保守处理。中心计数接口由当前正整数约束扩展为明确版本的有限正计量系数，提供旧版本兼容、冲突检查及回归验证；新格式在实现验收前不宣称可用。材料mol%与来源公式单元的对应基准须明确，不得将公式任意倍乘约成整数而沿用原权重。
6. **分层报告覆盖与资格。** 分别输出公式可解析率、来源语义核查状态、中心映射支持率、各项属性可用率和全部必需描述符的联合支持率。每项注明分母，按记录、唯一物种、DOI及既定分区汇总，保存逐条状态和排除原因。未知、冲突、不支持及角色缺席分别记录；任一必需正含量组分不支持则该记录不进入正式增强特征，不忽略该组分或重新归一剩余组分。S1-A报告数据/映射资格；S1-B完成后另报实际计算覆盖，不能将资格覆盖冒充已生成特征。
7. **保留历史和比较条件。** 原始数据、历史治理结果、冻结快照、旧目录版本及历史报告不可覆盖，新证据、更正、映射和特征构建单独留存。后续F_base/F1/F2须在同一事实快照、共同支持子集、既定DOI分区、相同CV折及配对算法/参数上重训；更正事实带来的变化与描述符增量分开说明。支持规则在查看本轮模型分数前冻结。

本补充任务验收须同时满足：

- 首批39条记录均有可追溯处置状态，包含已确认、更正被否定、证据不足或来源冲突；无需全部更正或全部转为支持。未核实的疑似错误不得进入正式增强特征，不因此把整条原始记录标为已核验。
- 经审核的多中心、小数计量及碳酸盐案例可复现；回归验证覆盖元素计量、公式单元权重、来源角色、冲突隔离、旧版本重放和拒绝静默修改。实际特征聚合、换序/合并不变性及预测一致性在S1-B/S2对应验收。
- 重新运行S1-A覆盖检查并保留与v1的差异、分母及原因，记录所用属性、映射、证据、规则及实现身份/哈希；不设置必须达到100%覆盖或必须提高模型分数的门槛。
- 原S1-A的属性来源与许可适用性、存储迁移、幂等/冲突检查及查询验收仍须完成，本补充任务不能替代这些要求。

S1-A通过后进入S1-B正式计算与F1/F2特征构建，再进入S2模型比较及训练预测框架，最后S3整体验收。证据不足者按冻结规则隔离并保留原因；不得为提高覆盖率或模型分数放宽来源要求、追加描述符或跳过阶段验收。

## 3. R1：完整组成与基础预测模型

### 3.1 特征

- `F0`：保留现有`design-features-v1`及历史运行，原函数和序列化语义不变。
- `F_cond`：仅四项核心工况，作为材料信息增益对照。
- `F_base`：四项工况＋来源角色/物种的材料mol%向量，是R1工作特征集。

仅用当前训练折的正含量组分建立物种角色词表，合并同角色同物种并稳定排序。完整组成中缺席的词表项为0，不做组成中位数填补。验证/测试中的未见键单独标记，不无提示丢弃；可计算历史诊断预测，但区分可完整编码与含未见键的记录。

独立预测遇到训练词表外的正含量组分时返回`unsupported_species_role`，不返回可用预测。已有词表物种的新含量组合可预测，并提示工况/组成范围越界。已知零含量项不触发未见物种拒绝，也不计入正含量组分数。

### 3.2 默认模型与训练评价

实施状态（2026-11-12）：默认比较已实现并完成运行验收，详见[进度](progress.md)及 [Python/脚本接口](api_contracts.md#r1-默认比较32)。3.3 R1独立预测另已完成真实冻结数据验收；3.4自定义配置仍待交付。

默认基准参数为Dummy(mean)、Ridge(alpha=1.0)、ExtraTrees(n_estimators=100, min_samples_leaf=2, random_state=42, n_jobs=1)。Ridge使用训练侧标准化；完整输入不需要组成插补。默认值不是用户唯一选择，S2同步提供第3.4节配置入口，支持已接入模型及白名单参数；近期不强制新增CatBoost/XGBoost或自动搜索。

默认在原train内做固定3折GroupKFold，DOI为组，比较F_cond/F_base和三种模型。固定输入排序及GroupKFold配置，持久化逐记录折归属；每折从原始受限输入重新fit词表与缩放，不复用全train词表。默认train不足3个DOI组时停止CV，不自动减少折数；自定义折数按第3.4节预先校验。

选模主指标为**训练集折外（OOF）预测的论文等权MAE**：先分别计算每篇DOI内全部OOF记录的MAE，再对DOI等权平均；不以三折MAE的简单平均替代。逐行MAE、RMSE和各折指标为辅助报告。主指标包含筛选后全部OOF记录的原始诊断预测，含未见物种或输出越界的记录不因误差被删去；入口可用性另行统计。

R1在F_base的三种模型中按主指标选工作模型；精确同分时按`dummy`、`extra_trees`、`ridge`顺序决胜。F_cond只作材料信息增益对照，不自动替代组成预测模型。选定后仅在原train重训词表、缩放器和模型，输出原validation开发评价，不在validation重新拟合或重新选模。

原test已被查看，仅作注明身份的历史对照，不用于本轮选模。无需等待新数据才能交付工程，独立确认性能另行规划；组数不足不回退随机行拆分。

## 4. R2：最小物化增强

### 4.1 只选两类属性

只纳入Pauling电负性和共价半径，固定来源/版本，半径采用同一体系和单位pm。定义、来源、版本、许可适用情况及文件哈希写入元数据。实现时核实来源，不凭记忆填写常数。

第一电离能、价电子构型、名义氧化态、O/M、形成能、Magpie全集和结构表征均推迟。暂不为两项属性强制引入pymatgen/matminer，优先使用覆盖实际物种的经核实小表和显式计量映射。

### 4.2 映射与聚合定义

使用`reported_active`（来源active_comp，对应当前compound）和`reported_support`，表示来源角色，不宣称真实活性位。为实际物种建立版本化白名单，记录化学式、中心元素计数和证据。例如Cu→Cu:1、In2O3→In:2、ZrO2→Zr:1、SiO2→Si:1、BaCO3→Ba:1、K2CO3→K:2。

中心元素按物种显式定义，可包含多个经确认中心及有限正小数计量，不严格限于金属；不简单删除O后把碳酸根中的C混入统计，材料mol%原样保留。确定计量的复合式按第2.5节核查并登记，不定比、复合别名或来源语义未确认的式子标为unsupported。语法解析仅辅助核查，不自动赋予正式资格；只实现实际物种白名单和必要负例识别，不先建通用解析器。结果称为中心元素属性聚合描述符，不作为化合物实测物性。

角色r内，组分含量为c_j、已确认中心计数为n_(j,e)、属性为p_e，计算：

`mean_p_r = Σ_(j∈r,e) c_j × n_(j,e) × p_e / Σ_(j∈r,e) c_j × n_(j,e)`。

权重为角色内中心元素原子数，不是直接对所有元素按材料mol%平均。角色不存在时，含量和组分数为0，属性均值与跨角色差值无定义；模型数组用0占位，以正含量组分数显式表示角色缺席，中间记录保留not_applicable状态，0不解释为实测物性。角色存在但属性缺失则排除记录，不插补。

### 4.3 固定小特征集与比较

| 特征集 | 在F_base上的增量 |
|---|---|
| F1 | reported_active总材料mol%、正含量物种数、电负性均值、共价半径均值，共4项 |
| F2 | F1＋reported_support同样4项＋active减support的电负性差、半径差，共10项增量 |

同角色内换序不改变结果。跨角色差值固定方向，交换active/support语义应改变有向差值，不要求跨角色交换不变。

R2比较F_base/F1/F2，算法和参数与R1相同，筛选规则不随误差调整。三者在同一R2子集、DOI分区和CV折上重训；不将R1全体成绩与R2子集成绩直接相减。F_cond可在该子集复算作辅助对照。

R2沿用R1的全部OOF论文等权MAE，在F_base/F1/F2×三种模型的固定候选中选择工作组合；精确同分先按F_base、F1、F2，再按上述模型顺序决胜。报告同一算法下的特征对照，区分特征增量与算法改变。支持规则和候选清单在查看本轮分数前冻结；不得按validation/test成绩改规则或扩充候选。若F_base胜出，明确结论为本轮未选用物化增强，不声称增强有效。

同步更新预测校验、物种映射和属性表绑定；指定F1/F2模型时任一正含量组分不支持则返回原因，不静默退回R1。F_base仍按其绑定的R1特征规则预测；R2的同子集比较不暗中改变F_base定义。F1/F2仍含F_base，沿用训练词表支持边界；属性可计算不代表验证了新物种外推。报告筛选前后各分区记录/论文/组成签名数、覆盖损失及排除原因。

## 6. 评价、验收与失败行为

报告逐记录MAE/RMSE（百分点）和各DOI的MAE等权平均；R²在样本不足或目标无方差时标明不可算。报告组成签名覆盖、未见物种及工况越界，不把总体分数等同于新配方泛化。

| 验收项 | R1 | R2增加 |
|---|---|---|
| 完整输入 | 缺组分筛除并记录ID/原因，不改原件/快照 | 属性/物种不支持筛除，覆盖损失可见 |
| 计量正确 | mol%不冒充at%，确认缺席为0 | 中心计数/权重明确，碳酸盐不混入错误中心 |
| 可重复 | 固定DOI折、参数、词表、清单和哈希 | 属性/规则版本及哈希绑定 |
| 无泄漏 | 目标/DOI/样品名不入输入，每折独立fit | 支持规则不按测试误差调整 |
| 同条件对照 | F_cond/F_base同记录同折 | F_base/F1/F2同子集同折 |
| 可预测 | JSON可加载预测，非法/未见组分拒绝 | 同一入口调用属性规则，不静默降级 |
| 处理一致 | 训练完成与重载后同输入预测一致 | 角色内换序、同组分合并结果不变 |
| 数据准备 | 已有/导入/计算职责明确，版本入库可查 | 属性/映射幂等导入、冲突拒绝及计算溯源 |
| 参数入口 | 默认与自定义训练可调用，非法参数报错 | 可选增强特征，同子集对照固定算法/参数 |

对失败路径增加必要单元测试和一次端到端集成验证；实现后运行现有pytest、ruff check和格式检查。仅修改本方案不算新功能通过测试。本阶段不把SHAP、校准区间、复杂适用域或大规模调参设为门槛。

对OOF、validation和已查看的test分别报告以下三层结果，不混合分母：

1. **输入筛选覆盖：** 相对于父分区的保留/排除条数、DOI数、组成签名数及各原因；R2同时列出相对R1的覆盖损失。
2. **全体诊断：** 对筛选后全体记录计算原始预测误差；未见物种诊断会忽略其词表外维度，必须附未见键和不可用状态，不能称为入口可用预测。非有限值或计算失败时列出记录ID并标明全体指标无法完整计算，不静默缩小分母。
3. **入口可用性：** 按绑定规则统计可用（含caution）与拒绝的条数、比例、原因及DOI覆盖，并报告可用子集指标。每折按该折训练词表和范围判定；最终留出按原train重训模型判定。无可用记录时指标为null并说明原因，不算作零误差。

比较特征时另报告共同可支持子集，避免F_cond忽略组成限制或不同模型输出越界造成样本差异。该子集仅用于辅助误差比较，不能替代全体诊断主指标；公开每个候选各自的入口可用率。选出的模型即使工程可运行，也不自动证明适合实际使用。

R2检验的是已支持物种范围内的物化增量；它仍依赖物种词表，不能据此宣称已解决新物种外推、跨家族泛化或真实样品独立性。本阶段完成属于工程交付，性能研究结论按上述分组误差和覆盖如实限定。

## 7. 模型路线及后续扩展

1. 有覆盖证据后再建标准化家族、助剂角色和相类型，保留来源与推断证据两层信息。
2. 再比较独立物化表示、未见组成分组、通用元素统计和家族标签；新物种支持策略单独版本化。
3. S2同期检查家族标签及样本/DOI覆盖，满足条件时比较A统一模型与B1相同特征单家族模型；不足则记录跳过原因，不凭样品名强行分类，不阻塞统一模型。B2专属特征有依据后加入，不提前采用专家架构。
4. 第一电离能、价电子、O/M、氧化态按覆盖和增益逐项引入；形成能、结构F3另定来源/状态和输入条件，不自动列为R2任务。
5. 甲醇选择性、收率、STY逐目标审核，不用关系式补标签，不将转化率模型称为甲醇产率模型。
6. 实验筛选和闭环留后续，不影响当前训练和预测交付。
