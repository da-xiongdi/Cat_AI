验收范围为固定输入上的 R1/R2 正式比较及其独立核算；不包含 S3-02 的端到端整体验收。验收操作者为 Codex，任务最终状态以管理库登记记录为准。

| 标准 | 验收依据 |
|---|---|
| C1 同输入和配对 | R2 使用同一事实快照、S1 v4 的 553 条共同支持记录和原 DOI 分区（train/validation/历史 test 为 454/47/52 条，26/6/4 篇）；九候选使用相同记录与 DOI 分组折、配对模型参数。输入与绑定、折隔离、候选数、包加载及拟合范围检查见[输入清单](../artifacts/reports/s3-01-20261118-01/inputs.json)、[有效配置](../artifacts/reports/s3-01-20261118-01/effective_configs.json)和[运行核查](../artifacts/reports/s3-01-20261118-01/01-b-verification.json)。 |
| C2 报告与选择 | [可读比较报告](s3_01_comparison.md)列出筛选损失、全体诊断、入口可用性和共同可用子集；[独立核算](../artifacts/reports/s3-01-20261118-01/verification-01c.json)从逐条预测复核论文等权 MAE 和选模。按全部 OOF 记录选中 F_base/ExtraTrees（5.373464 百分点），本轮未选用物化增强；validation 不选模，test 为已查看的历史参照。 |

R2 ExtraTrees 的 F1、F2 相对 F_base 全部 OOF 配对 MAE 分别增加 0.557559 和 0.514140 百分点。入口可用子集另列，不替代主指标；R1 数据规模不同，其分数不能直接作为物化增量。逐条数据、各候选/分区指标、共同子集、配对及逐 DOI 结果和适用边界均由比较报告链接。缺少经核验的逐记录家族标签，A/B1 家族对照全部跳过；来源接受不等于逐行原文核验，绝压沿用既有假设。历史 R1 和 S2 烟测分数已在本轮规则冻结前查看，不声称在所有分数揭晓前预注册。
