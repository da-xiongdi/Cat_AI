## 4. 25 字段映射及需要修正的语义

以下映射由显式 `themecat-v2` 适配器采用；旧 v1 行为和数据库历史不变。字段全量原文继续留在 `raw_payload`，逐行原文核验和指标定义仍待补充。

| 原始字段 | 目标表达 / 处理 | 升级要点 |
|---|---|---|
| `reference`, `doi_link` | source + 规范 DOI 别名映射 | 原字符串保留，论文分组采用核对后的 source 关系 |
| `catalyst_name` | 原文样品标签、material_family 辅助标签 | 名称不是独立配方/批次真值，也不直接作为材料设计特征 |
| `catalyst_composition_available` | 保留原文和 Yes/No 解析状态 | 不把 Yes 等同人工核验；No 不补零 |
| `starting_material_active_1`, `starting_material_2` | 活性组分还原前/初始材料信息 | **不直接等同实际合成投料前驱体**；当前适配器写入 synthesis.precursors 的解释需版本化修正 |
| `active_comp_1`, `active_1_percent`, `active_comp_2`, `active_2_percent` | recipe.components，材料物种与材料 mol% | 顺序不具有独立科学意义，角色仅按来源保留 |
| `support_comp_1`, `support_1_percent`, `support_comp_2`, `support_2_percent` | 同上，support 角色 | 范围为全部材料组分；不直接作为元素原子分数 |
| `catalyst_surface_area_m2_g`, `mean_pore_diameter_nm` | 独立 characterization | 来源可能含作者换算；不强称全部是直接测量值，不进入新配方设计模型 |
| `temperature_k` | test.temperature，K | 不反推原论文摄氏温度或重复换算；作者温标换算约定需留 provenance |
| `pressure_bar` | test.pressure，bar | 压力类型仍需证据，未知不赋 bar(abs) |
| `pH2_pCO2_ratio` | 独立反应物比值 Measurement | 压力比/摩尔流量比的来源说明保留；不是完整 feed 的两组分百分比 |
| `GHSV_nlph_gcat` | 质量归一气体体积流量 Measurement + 基准 | 记录参考温压、质量分母、reactants_only 范围及数据集定义来源 |
| `catalyst_load_g` | test.catalyst_mass | 工况/装样量，进入模型须做有无该特征的对照 |
| `CO2_conversion`, `selectivity_CH3OH`, `yield_CH3OH`, `STY_g_per_gcath` | 四个独立 observation，保留原值与定义 | 标明“来自数据集”、作者派生/原文直接值若可知则另记；不把 CSV reported 误称原实验直接测量 |

v2 用 `mass_normalized_volume_flow` 表示质量归一流量；体积 GHSV 继续使用既有 `ghsv` 和 `ghsv_basis`。两者分别要求质量/体积基准，详见 [接口契约](api_contracts.md)。

**门禁不能只增加一个新字段便视为解决。** 现有 govern 强制要求体积 GHSV、完整 feed 和整记录所有指标定义。v2 需要明确支持“有已知反应物比值和质量归一流量、完整惰性组成未报告”的用途规则，不把这种合法数据表示错误地当成缺体积 GHSV；也不静默删除旧 block。压力、来源、数值、指标定义及人工审核等要求继续生效。当前严格快照不变，逐目标/逐观测独立冻结若要支持，另设版本与负例测试。

## 5. 审计脚本与结果解释

仓库版使用 CSV 原始字符串判重，分别统计全空行和非空行，保留物理行范围；缺失与无法解析数字分别计数，拒绝 NaN/Infinity。百分数、正数等仅标出待复核项，不修改 CSV、SQLite、curated 或 review。

默认不运行组成/收率/STY 关系式。显式 `--check-relations` 后，按数据集定义作**假设性诊断**：组成要求 available=Yes 且所有已列材料有有效含量、没有孤立的含量字段；NA 槽位只在此诊断场景视为未列材料，不是补成零。缺项、无效值、越界值不进入关系式。

- 组成偏差阈值 0.5 个百分点，与项目现有容差数值一致，仍不是审核通过条件。
- 收率关系偏差阈值 0.5 个百分点；STY 偏差阈值 0.01 g_MeOH/g_cat/h。它们是审计提示阈值，不是经过校准的实验误差界限。
- 每次可比较记录均输出原字段、计算期望值、绝对/相对偏差、位置及假设标记；期望值为零时相对偏差为空。
- 原值不覆盖，期望值不用于补标签，不进入训练；后续如需研究派生目标，另建有输入证据和计算版本的 derived 记录。
- 重复行保留在描述统计分母中；没有假定每行独立。

在项目根目录可复现（`--output` 必须换成尚不存在的新目录）：

```powershell
uv run python scripts/validate_themecat.py --input data/raw/46000f00323ac64a79f63777e54c05634e83d1a6476176c8b6569122bd03dfbd.csv --output artifacts/reports/themecat-audit-new --check-relations
```

输出：`quality_summary.json`、`column_quality.csv`、`row_diagnostics.csv`。脚本退出 0 表示完成且 MD5 匹配，2 表示完成但输入并非该官方 MD5，1 表示解析/IO/输出冲突失败。0 **不表示数据通过科研准入**。报告目录必须与原件目录分离；已有目录拒绝覆盖。

本次[实际报告](../artifacts/reports/themecat-20261110/profile-final/quality_summary.json)复现既有计数。在显式假设下，组成可比较 728 行中 9 行超阈值，收率可比较 779 行中 2 行超阈值，STY 可比较 712 行中 0 行超阈值。具体行见 [诊断清单](../artifacts/reports/themecat-20261110/profile-final/row_diagnostics.csv)。这些仅用于安排复核；关系式吻合不证明样本、定义和原实验正确，未据此解除治理 block。

## 7. 第一批可用数据的原始完成标准与当前执行策略

以下为最初要求逐条原文核验的标准。后续用户决定暂缓B3、接受公开数据集来源，并对未注明压力类型采用绝压假设；当前593条快照是在这项显式策略下冻结，尚未满足下列原始标准中逐条原文定位与实际人工核验的部分。来源接受不生成虚构审核，其他数值、完整性、治理与目标门禁继续保留。当前数据可用于有明确限制的探索性研究，不能称为逐条原文已核验的数据集。

第一批交付应是“一组定义清楚、有原文定位且能冻结的记录”，不要求所有 821 行都通过，也不能拿空合格集继续训练：

1. raw 哈希、版本、来源与资料使用范围可追溯。
2. 指定记录的组成/流量/比值表达正确，关键压力和目标定义有证据。
3. 修订产生新版本，原始行、旧报告和旧审核可重现；旧审核不自动批准新内容。
4. 无 block 后才创建 curated，完成实际人工核验后才 freeze。
5. 资格清单、快照、未决重复/身份关系和覆盖统计齐全。

随后才按足够的独立论文/样品组实施训练和评价。详细合成工艺缺失的限制要写入模型卡；本阶段不能产出经数据验证的焙烧/还原/pH 优化建议。未来补充工艺或自有实验数据时再登记新的来源范围与用途规则。
