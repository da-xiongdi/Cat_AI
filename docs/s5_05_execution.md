# S5-05 综合模型评价与收口

主计划登记章节。前置为 S5-02、S5-03、S5-04 验收。S5-03 若按批准范围验收证据不足，综合报告应包含该缺口及复启条件。 [S5 总计划](s5_implementation_plan.md)

## 01 综合比较、误差与稳定性

1. 收集 S5-01 协议、S5-02 固定算法的特征消融、S5-03 铜基配对、S5-04 固定特征的算法对照与寻优。核对成员、五折及铜基投影、选择轨迹、单位、版本和分母。比较模型时使用同一留出且逐记录配对，分别报告整体诊断误差、入口覆盖、共同可用误差和 DOI 分层。
2. 按预登记目录运行有限的 E05 特征×算法组合。每个随机划分只用其训练五折完成选择，以其全训练集重拟合并锁定。已有同一模型锁和留出清单的结果直接引用。评分后描述固定基线、报告臂及候选的误差、偏差、残差分布和失败情况。候选与基线的判定按预登记训练侧规则留痕；S5 留出成绩仅用于报告及局限说明。待进一步研究的问题另记录。
3. 用训练折波动及预登记的重复随机种子评估稳定性，报告每种子的记录等权 MAE、RMSE、论文等权 MAE、覆盖与配对差值。种子成员可重叠，逐种子报告并注明相关性。若执行了 DOI 诊断，单列其内部评价结果。历史 S4 保留原报告和出处。

## 02 特征贡献与适用范围

1. 复用 `modeling/diagnostics.py` 及 D 阶段已有诊断。以同条件消融和固定模型的块置换为主，检查工况、组成、物化和 Cu 特征块的贡献及训练折间稳定性。说明置换评价的成员、相关特征影响和统计分母，特征重要性用于解释模型行为。
2. 按训练数据的组成、来源角色及四工况范围汇总适用边界，报告无法编码、超范围警示和入口不可用记录。新催化剂、未见组分与跨体系表现列为模型局限和后续研究，S5 的报告依托既有内部评价。树间分散度如使用，仅作经验诊断。D-06 独立外部评价等待合格新来源。 [D 计划](d_implementation_plan.md) · [D-06 流程](d06_evaluation_workflow.md)

## 03 归档与正式审查

1. 交付 `final_report.md`、`model_card.md`、`limitations.md`、`evidence-sha256.json`，附数据、折、特征、算法、依赖和运行版本，预测、状态、汇总、适用域结果及下一阶段新 DOI/铜基覆盖缺口。单列历史基线、候选以及各自可用范围。新模型卡以 UTF-8 检查可读性，证据链接对到固定文件散列。
2. 研究报告写入新 `artifacts/reports/s5-05-<tag>/`，批准的候选写至新 `artifacts/models/s5-<tag>/`。按既有成果索引、运行台账、验收检查项关联任务；对计划、路线和成果固定版本进行往返和恢复抽检。WB-07 后续使用冻结的脚本契约。

## 验收

| 编号 | 必需证据 |
|---|---|
| evidence | 所有已执行比较及未执行事项能按任务、配置、版本、ID 与分母追溯。数据与代码可重放，历史包和 S4 证据通过各自版本的回归检查。 |
| conclusions | 预测误差、稳定性、特征贡献、适用范围和铜基配对均有证据，报告注明内部评价及外推局限。候选或保留基线的决定可追溯到预登记规则及训练侧证据。 |
| release | 研究总报告、可读模型卡、限制及下一阶段缺口经审查，工作台可从任务直达主计划和验收证据，审查记录绑定固定版本。 |
