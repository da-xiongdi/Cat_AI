## 入口原型

`scripts/run_research_experiment.py` 提供 `preflight CONFIG`、`train CONFIG --output NEW_DIR` 和 `score RUN_DIR` 三个独立操作。配置样例为 [research_preflight_example.json](../configs/research_preflight_example.json)，其中清单哈希绑定初步划分。预检不训练，验证视图、快照、来源和划分哈希、成员完整性、折及 DOI 隔离；目前只支持 S4-02 的已确认无重复组口径，遇到未决或需要合并的重复身份会拒绝，尚不能推广到其他重复规则数据集。

训练生成配置、划分、交叉验证结果、模型、日志及环境和文件哈希锁；评分重新校验锁和运行环境，在新建的 `holdout` 目录输出逐条预测、误差和可用率，以及实测对预测、残差和误差分布 SVG。评分目录已存在时拒绝覆盖。只应加载可信来源的模型文件。小样本测试以临时目录和 Dummy 模型验证两阶段、隐藏测试标签、评分重入及篡改拒绝，不代表正式模型结果。

划分生成脚本支持 `--seeds 42 43 44 --train-fraction 0.8 --folds 5` 等参数，并同时生成 DOI、随机及铜基投影清单；每个训练运行显式锁定一份清单。`train-batch CONFIG_DIR --output NEW_DIR` 可逐个执行生成的配置，并保存独立结果与批次状态；它不执行留出评分。

可使用 `scripts/configure_research_experiments.py configs/research_plan_example.json --output NEW_DIR` 从计划生成多种子清单和逐次运行配置；评分配置可选择指标与预测、图表输出。训练失败记录在新运行目录的 `failure.log`，环境锁记录 Python、平台及已安装包版本。预检支持显式确认的重复组；未知身份拒绝进入。模型训练接口依据快照目标定义取值，但目前仅对 CO₂ 转化率数据完成实际验证。

现有 R1 固定包与 S3 R2 固定包已成功加载并对一条记录预测；相关历史单元测试通过。评分输出带文件哈希清单，失败写入日志并保留目录，失败后可显式 `score RUN_DIR --retry`；成功评分后禁止再评分。研究包提供 `predict_payloads` 接口，输入为现有领域 payload，原始预测只有状态为 `ok` 或 `caution` 时可用，仅加载可信包。计划生成器支持通过 `dataset` 指定遵循相同视图、台账和快照契约的数据版本，并以 `strategy` 选择随机或 DOI；S4 三组共享铜基测试使用投影选项。不同来源和目标仍需满足特征目录和目标定义要求，目前只在 S4-02 视图上验证。

隔离小视图使用真实预检、训练、评分和模型重载，覆盖随机、DOI、F_base/F1/F2 与评分失败重试；跨 DOI 已确认重复组使用合成记录验证。[归档检查](../artifacts/reports/s4-03-verification-20261120-v3/verification.json)包含 26 项测试通过、固定清单重放、九份配置预检和两个历史包加载预测；没有正式对照训练。
