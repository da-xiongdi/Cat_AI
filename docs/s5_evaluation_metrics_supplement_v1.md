# S5 统一评价指标补充 v1

2026-11-24。适用于 S5-04 算法及超参数实验和 S5-05 综合评价；作为对各执行计划的版本化补充，不改写 S5-01 已验收的冻结协议或历史成果。

S5-04 对每个候选分别报告训练 OOF、每折和留出集的记录等权 MAE、RMSE、R²、覆盖率及分母，并保留逐条状态。对同一划分和同一阶段的全部比较臂，另在所有臂均为 ok/caution 且预测有限的严格共同可用记录上，逐臂报告相同指标及共同 ID；各折分别取交集。目标常数、少于两个有效记录时 R² 为 null 并记录原因；无有效记录的其他误差也为 null。报告各划分结果和折间、种子间稳定性，并说明重复划分的相关性。留出结果仅作报告。

S5-05 在原始逐条预测、状态、目标及成员可核对时补算既有实验的 R²，与 MAE、RMSE、覆盖率及稳定性并列；不可核对时记录缺口，不覆盖既有验收产物。只有相同数据成员、划分和阶段的模型可计算严格共同可用对照。留出集不得反馈选择。

R² 仅为科研及论文报告指标，不进入 s5-paired-v1 资格、平局、排序、回退或选模规则，也不以 R² 重新选择已验收模型。
