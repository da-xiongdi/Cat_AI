### WB-15-01 基线与展示规则

核对 `queries.query` 返回的分类任务、焦点、近期安排和主计划检测结果，确认任务依赖、交付物、验收项及固定证据的读取入口。盘点现有文档预览和路线深链接。用隔离样本覆盖已核对主计划、无关联、文件变化、章节缺失及阻塞任务。输出可复核的任务 ID、文档路径、章节与预期状态清单。

### WB-15-02 分类近期任务视图

在项目管理导航接入「下一步工作」，默认科研，支持切换到工作台建设。人工近期安排按已存顺序显示，焦点明确标记，自动候选按就绪情况、现有优先级、计划日期和任务 ID 稳定排序。人工与自动来源按任务 ID 去重。已完成和已取消项归历史，类别不符或焦点失效显示待复核。空视图说明当前暂无近期任务。

沿用现有依赖和验收证据判定，展示具体前置任务及阻塞原因。计划未核对、缺交付物或缺验收项时，保留相应提示。`in_progress` 进入任务详情，`in_review` 进入现有验收入口。列表浏览只读。

### WB-15-03 任务节点与计划章节关联

用已登记的主计划引用建立从任务节点到文档章节的链接。打开时按项目、任务和引用身份校验，复用工作区路径边界与实际文件检测。复用现有文档预览，只为目标章节补充稳定定位。以同一份读取内容核对哈希和定位章节，使本次展示与检测结果一致。

有效且已核对时直接定位章节。当前章节仍可定位但文件已变化或尚未核对时，允许查看当前内容并明确提示「计划待核对」，同时展示已有核对记录。无主计划时显示「待关联主计划」，文件缺失、章节缺失、同名歧义或路径无效时提示原因，保留已有引用和历史。主计划及参考计划在任务详情中使用相同的检测口径，关联登记和重新核对复用 WB-13 服务。

### WB-15-04 页面联调与异常复核

在隔离副本分别从科研、工作台建设的近期任务节点打开对应计划章节，再返回原任务和类别。科研任务详情沿用 WB-14 路线入口。覆盖无活动近期安排的实际数据形态，以及同文档不同章节、多份计划、历史任务和跨类别依赖。通过现有服务更正错链或重新核对文件，验证页面恢复正常且旧记录可查。遇到正式库缺少科研当期待办或缺少明确文档依据时，按实际状态展示空态或待关联，保留待核对清单。

### WB-15-05 专项验收与交付

完成第 5 节的服务、Web、浏览器和备份恢复验证。记录实际代码、配置、计划和验收证据版本，核对既有任务、验收及科研数据。完成隔离部署演练后，按现有任务与验收服务完成正式交付，整理 WB-16 可复用的页面入口与字段清单。

## 4. 执行安排

1. **开工**。从 WB-15-01 开始，复核基线与编号。父任务 `WB-15` 的主计划指向本文件「1. 目标与范围」，子任务分别指向第 3 节同名标题。正式登记使用 `workbench` 类别，填写目标、交付物、检查项及真实依赖，并记录实际发生时间。
2. **开发**。默认按 WB-15-01 → WB-15-02 → WB-15-03 → WB-15-04 → WB-15-05 推进。第二、三项共用第一项的约定，先形成可查看的分类视图，再接通计划入口。每项完成对应检查后进入下一项。
3. **联调**。在隔离副本用两类样本走完「近期任务 → 主计划章节 → 原任务」。核对正式数据下科研空态与实际工作台建设入口。按照已有任务证据处理关联，待核对项随交付记录列出。
4. **发布**。先备份正式管理库及关联文档，演练部署和恢复；发布时记录授权范围内的变更与实际验证结果。子任务逐项验收，父任务汇总证据后单独验收，再进入 WB-16。回退时保留发布后写入，必要时通过现有管理服务提交反向修订。

## 5. 专项验收

| 场景 | 通过条件 | 验证方式 |
|---|---|---|
| 两类任务、空态与历史 | 类别切换、人工排序、自动去重、无焦点、空态、历史与就绪提示和任务数据一致 | 服务与 Web 集成测试 |
| 真实文档和章节定位 | 从节点一步进入登记章节；同文件不同章节、参考计划、任务详情返回以及科研路线互定位均正常 | Web 集成测试、Edge 实测 |
| 无主计划、未核对、文件变化或章节失效 | 提示可区分；列表加载后修改文件，打开入口时显示当前结果，保留历史；更正关联或重新核对后恢复 | 临时 Markdown、Web 集成测试、Edge 实测 |
| 依赖及验收证据 | 跨类别依赖可追溯，人工置顶仍显示阻塞，失效证据影响就绪提示，计划入口可定位时仍可查阅 | 服务与页面对照 |
| 项目边界和并发 | 跨项目、错配引用、越界路径被拒绝；现有写入流程拒绝过期修订，重复请求保留同一结果 | 计划引用服务及 Web 集成测试 |
| 旧入口与发布恢复 | 旧任务、成果、决策、文档、预测入口通过回归；浏览前后库记录一致；备份恢复和科研数据隔离核对通过 | pytest、Ruff 检查及格式检查、管理库与文件对照 |

浏览器覆盖 1366×768、1920×1080 和 390×844。验收记录注明实测环境、代码和配置版本、证据位置及待办项。
