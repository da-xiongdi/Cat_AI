# WB-04 本地工作台

2026-11-17 更新：原先待补的真实浏览器主流程已通过 Edge 三种视口验证，实际库导入与恢复结果见 [WB-05](wb05.md)，导航及研究分类见 [WB-08](wb08.md)。下文原交付时的待办描述保留为历史。

安装 Web 可选依赖后启动：

```powershell
uv sync --extra web
uv run catalyst-ai workbench serve --config configs/workbench.yaml
```

浏览器访问 `http://127.0.0.1:8765`。配置 `workspace` 相对配置文件目录解析，`database` 相对工作区根目录解析；项目 ID、名称及端口由 `configs/workbench.yaml` 指定。服务仅绑定 127.0.0.1，并检查 Host、写请求来源及 CSRF 令牌；输入和预览内容按文本转义。部署在其他网络地址或多人共享不在本地首版范围内。

第一次启动会初始化独立管理库、项目及索引工作区，不自动导入 WB-01 任务草案或既有成果。已有管理库从 schema 2 升级至 3 前使用 SQLite 备份接口创建 `.v2.backup`；已有同名备份时停止以避免覆盖。真实项目首批导入和备份恢复验收属于 WB-05。

页面包括总览、任务、成果、决策、文档和全局搜索。任务可创建、编辑、设置依赖及焦点、流转、提交验收和确认完成；成果可登记、刷新、预览和下载已校验的版本；文档使用成果类型 `document` 登记；决策可新增、修订、关联任务和导出 Markdown 草稿。历史 ADR 可将源文档登记后浏览，不会自动创建管理决策。任务列表筛选条件保留在 URL。

每项修改填写操作人。多标签页的任务和决策使用期望修订号，发生冲突时返回错误并保留输入，核对最新版本后再修改。验收支持固定的成果版本或文字说明；对阻塞、取消、退回和重新打开等操作须填写页面提示的原因或处理记录。标准每行输入 `编号 | 内容`，可选标准在行尾附加 ` | optional`。验收和状态约束以 WB-02 服务为准。证据预览前重新校验内容，已经变化时先刷新索引。

当前文档预览为转义的纯文本；普通附件仅支持可解码文本预览，其他文件可下载。页面列出最多 500 个成果，索引服务可分页；来源登记和索引不自动发现所有文件。模型包只提供清单预览和哈希校验，不在界面中反序列化模型。历史 ADR 自动导入、首次项目数据选择、备份恢复操作说明及端到端实际项目验收留待 WB-05。

验证记录：任务创建至确认验收、过期编辑输入保留、成果登记及预览下载、决策修订和管理库 v2 升级由隔离数据库的 HTTP 测试覆盖。当前环境 Edge 无头进程未输出页面或截图，真实浏览器的桌面和窄屏布局、导航及表单交互仍待验收。
