# WB-08 分组导航与研究证据管理

2026-11-17 交付。四组十一入口可达，筛选、候选与实验入口显示待接入；原任务、成果、决策和文档路由继续可用。

`/research?kind=claims` 管理独立于任务执行状态的分类：planned（规划）、implemented（已实现）、validated（已验证）。`/research?kind=issues` 管理研究中、已有方案待验证和已解决的问题，可关联项目内 task_id、decision_id。更新携带预期修订号，每次保存追加历史，保留操作人、时间、范围、结论、限制和固定证据。证据失效时保留历史并提示复核，总览有效分类统计排除失效项。

分类提升按对象检查必需角色。模型需 snapshot/features/target/split/metrics/run/reproduction/domain；候选需 candidate/preparation/experiment/raw/conditions/metrics/review；回灌需 experiment_review/snapshot/old_model/new_model/training/paired_review。缺项返回具体列表。证据引用为已索引 id、version（文件 SHA-256）、role，必须属于当前项目且可用。角色代表操作者审查范围，系统不根据文件存在自动推断科学有效性。

页面使用 JSON 表单。分类内容包含 title、object_type、classification、可选 task_id、scope、conclusion、limitations、evidence。问题内容包含 title、status（researching/proposed/resolved）、可选 task_id/decision_id、scope、conclusion、evidence。新建预期修订号为 0。复制查询结果中的证据时移除附加的 status。

GET/POST `/api/workbench/v1/claims` 和 `/api/workbench/v1/issues` 提供相同服务；POST 参数为 id、content、expected_revision、request_id、actor，沿用 CSRF 和来源检查。GET `/api/workbench/v1/exports/progress` 导出任务、研究审查、问题、固定证据版本和生成时间。来源核验范围在数据基础的来源 reviews 管理。

总览显示来源条数、按最新修订统计的研究分类、固定快照测试记录数及版本/观察时间。材料数和实验复核统计显示待接入，200+ 汇报不计入样本。实际库保存 S1-A 548/593 历史反馈、553/593 工程范围和 DIFF-S1B；工程任务完成与科学验证分类分开。S1-B 验收仍需逐项复核。

管理库 schema 5→6 先备份后增加 research_record。完整备份恢复保留审查修订和固定证据，兼容 schema 3–5 旧备份并迁移恢复副本。浏览器与恢复验证记录见 WB-05。
