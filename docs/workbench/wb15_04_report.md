# WB-15-04 页面联调与异常复核

2026-11-20（Asia/Shanghai）。联调使用临时管理库和独立的 Markdown。正式数据形态在管理库一致性副本上核对。

| 场景 | 联调与复核规则 |
|---|---|
| 两类任务往返 | 科研 R 与工作台 W 从「下一步工作」进入同一文档的不同章节，预览可返回原任务和原分类。任务详情也可打开独立文档中的参考计划。 |
| 改类后的人工安排 | 将 W 改到科研分类。旧分类仍展示人工安排并提示「待复核」，主计划入口继续有效，从预览可返回原分类。 |
| 文件或章节异常 | 列表加载后修改正文、改名、加入同名标题或移除文件。打开页面时重新读取和检测。仍可定位时展示当前正文，无法定位时提示原因，历史核对记录可查。更正引用及重新核对沿用 WB-13 服务。 |
| 依赖与验收入口 | 工作台任务 W 人工置顶时仍提示其科研前置 R；固定证据失效会重新阻塞就绪。`in_review` 任务直接定位既有确认完成入口。 |
| 科研路线互定位 | 从科研任务详情进入主归属路线节点，可从该节点回到任务详情；文档使用现有文件预览。 |
| 正式数据形态 | 科研分类无近期任务，两类均无焦点及活动人工安排。工作台在验收前有 5 项自动候选。未关联主计划的科研任务按管理记录提示待关联。 |

列表与详情共用计划核对状态。文档预览用同一份读取内容计算哈希和定位，通过原生锚点打开章节，并在浏览器刷新时恢复预览区的定位。旧任务计划入口继续可访问。

章节链接使用 `/artifacts/{document_id}?task={task_id}&reference={reference_id}&category={category}#plan-section`。带计划引用时，现有文件预览展示实际读取的正文和核对状态。普通文档链接继续按已发布版本预览。
