# WB-16-03 任务、文档与成果筛选验证

2026-11-20（Asia/Shanghai）。已在工作区完成开发验证。正式验收及发布按 [WB-16-06](wb16_implementation_plan.md#wb-16-06-专项验收与交付) 执行。

## 列表契约

- `/tasks`、`/documents` 和 `/artifacts` 支持 `research`、`workbench`、`all`、`unclassified`。省略 `category` 时沿用项目级范围，显式传空值或非法值返回 422。先取筛选结果，再按 ID 排序和分页。显式分类默认每页 30 项，`offset` 和 `limit` 可写入 URL。
- 任务保留 `q`、`stage`、`status`。列表按 ID 统计已取消、有效完成和已完成但证据待复核的任务。详情、关联问题、决策和计划章节可沿 URL 返回原筛选范围。
- 文档支持按编号和登记路径检索。活动用途的明确类别、按名称明确适用范围的科研或建设方案、已核对的同项目活动计划引用可提供分类依据。用途与任务类别冲突、未核对或已变化的引用可在待核对范围查阅。独立有效依据仍支持该文档进入对应分类。
- 成果按同项目任务的验收、提交检查、当前模型运行或科研记录中的固定证据关联归类。各任务的交付范围、关联记录和原固定版本均可查阅。固定版本失效时保留可追溯的关联及待复核状态。共用项在全部范围按成果 ID 去重。
