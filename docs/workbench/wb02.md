# WB-02 管理库与任务服务

本阶段交付 Python 服务，不启动 Web，不自动导入 WB-01 草案，也不改动领域库。独立管理数据库由调用方显式初始化：

```python
from pathlib import Path
from catalyst_ai.storage.workbench import migrate
from catalyst_ai.workbench import service

path = Path("data/workbench.sqlite")
migrate(path)
service.create_project(path, "cat-ai", "Cat AI", request_id="project-1", actor="操作人")
service.create_task(path, {
    "id": "example", "project_id": "cat-ai", "title": "示例", "goal": "目标",
    "deliverables": ["报告"], "criteria": [{"id": "check", "description": "检查报告"}],
    "milestone": "S2", "stages": ["C"], "primary_stage": "C",
}, request_id="task-1", actor="操作人")
service.transition(path, "example", 1, "ready", request_id="ready-1", actor="操作人")
service.transition(path, "example", 2, "in_progress", request_id="start-1", actor="操作人")
service.submit_review(path, "example", 3,
    [{"criterion_id": "check", "passed": True, "explanation": "已人工核对"}],
    "检查完成", request_id="submit-1", actor="操作人")
service.accept_review(path, "example", 4, "验收通过", request_id="accept-1", actor="验收人")
print(service.get_task(path, "example"))
```

`migrate` 使用 SQLite `user_version`，已存在的旧版本在升级前用 SQLite 备份接口生成 `<数据库名>.v<版本>.backup`；已存在同名备份时停止，避免覆盖。版本高于当前实现时拒绝打开。不要对领域库调用此函数。管理库和被引用的文件都需要备份。

任务通过 `create_task`、`update_task`、`list_tasks`、`get_task` 管理，修改需传期望 revision；`add_dependency` 和 `remove_dependency` 仅在 planned/blocked 时可操作，并校验项目、循环和修订号。所有写操作要求全库唯一 request_id 和真实填写的 actor；相同请求重试返回原结果，同一 ID 携带不同内容会冲突。写操作、修订、活动和去重记录在同一 SQLite 事务中；锁等待上限为 5 秒，数据库繁忙时调用方可用同一 request_id 重试。

`transition` 支持方案中的状态变化；提交和确认验收分别调用 `submit_review` 与 `accept_review`。进入 ready 或开始需要交付物、当前标准以及已完成且证据可用的前置任务。提交需要每项必需标准有结果，以及对应证据版本或文字说明；结论应列明未解决项。确认要求必需项通过、引用的证据可用，并保存标准版本、结果、结论、操作者和 UTC 时间。阻塞需原因及恢复条件，解除需处理记录；取消、恢复、退回和重新打开需原因。完成后先重新打开才能编辑，修改标准生成新版本，不覆盖旧验收。

`set_evidence` 是供可信来源索引适配器使用的接口，登记项目内的证据 ID、固定版本、说明和观察状态（available、pending、changed、missing、invalid、read_error）。它**不读取或验证文件**，不能仅凭调用它推断文件有效；WB-03 应负责内容身份、哈希和实际检测。证据状态变化后 `get_task` 的 `evidence_needs_review` 和 `dependents` 提示影响，前置任务的验收证据不可用时会阻止就绪。只用文字说明的验收没有文件可自动复核，调用方应按实际验收范围使用。

错误：对象缺失抛出 `Missing`，状态、并发、依赖和幂等冲突抛出 `Conflict`，输入错误抛出 `ValueError` 或 Pydantic 校验异常；未来 Web 层负责映射为 404、409、422。管理服务不替代 WB-03 的索引、WB-04 的页面或 WB-05 的实际导入和恢复验收。
