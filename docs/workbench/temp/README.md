# AI辅助 CO₂加氢制甲醇催化剂开发｜项目管理工作台 v1.1

版本日期：2026-11-16。形式：单文件、离线优先的 HTML 项目管理工作台。

> **交付属性：**这是可在本地使用的网页，不是已上线的 ChatGPT Sites 或云数据库。科研状态按证据登记，默认空表不是“已完成”或“零研究成果”的事实判断。

## 1. 如何打开

- **直接使用：**双击 `index.html`，建议 Chrome/Edge。
- **更稳定的本地地址：**双击 `启动工作台.bat`（需本机安装 Python），打开 `http://localhost:8765/`。继续使用时应保持同一浏览器、主机地址和端口。
- **保存：**所有业务数据写入当前浏览器的 localStorage。重要更新后点击右上角“导出备份”，生成完整 JSON 文件。不同浏览器/文件 URL 可能不共享存储；清理浏览器数据可能丢失资料。**不要用工作台 HTML 文件当作数据备份。**
- **导入旧记录：**可在“证据台账与备份”中导入 v1.0 的 JSON。导入将覆盖当前数据，先导出当前备份；v1.1 会在保留旧记录的前提下增补两条资料索引与 S1-A 未完成任务。若处于同一站点存储空间，页面也会对现有 v1.0 数据执行一次兼容迁移。

## 3. 三类研发进展，严格区分

| 状态 | 含义 | 更改条件 |
|---|---|---|
| 规划内容 | 方案、目标、任务、技术路线或待完成工作 | 有明确的计划和验收标准 |
| 已实现功能 | 某项软件/数据管线/分析功能确已实施 | 关联已登记资料并填写具体实现说明；**不等同于科研验证** |
| 已验证成果 | 真实模型、催化剂或实验工作有可复核的结果 | 已核验原始数据或报告、结果边界和复核说明；模型及候选还设置额外条件 |

**资料已登记 ≠ 数据已抽取；样本已导入 ≠ 已核验；模型已运行 ≠ 有可迁移精度；候选已推荐 ≠ 催化剂有效；实验已录入 ≠ 已复核 ≠ 已回灌。**

v1.1 增强了证据控制：仅凭项目讨论、内部汇报或开发进展转述，不能将研发项标为“已验证成果”。候选配方只有关联真实、已复核且来源已核验的实验记录后才能标为已验证。模型验证需要数据集版本、目标、评价指标和划分/验证方法。所有界面校验仅约束用户录入，不能替代独立的原始数据审计。

## 4. 初始证据与最新补充线索

- `SRC-002`：汇报材料提到 **200+ 自有催化剂**与高通量实验平台，这是汇报口径，**没有 200+ 条原始数据自动入站**。
- `SRC-THEMECAT-2026`：根据项目讨论，**初期文献数据源选用 TheMeCat**。选型属于明确决策，不代表已经导入本地工作台的样本数据。
- `SRC-FEAT-S1A-2026`：根据 2026-11-10 提供的 VSCode 开发反馈，S1-A 覆盖报告显示 **593 条中 548 条具备映射及两项属性，45 条暂未支持，其中 InNi3O0.5 为 39 条**。反馈明确 **S1-A 尚未完成**。当前没有读取原始覆盖报告/数据库迁移文件，不计入已验证成果；该项资料状态设为“待核验”。
- 项目模型、虚拟筛选、实验表初始空白；不得根据工作台存在就推断研发已完成。

## 5. 推荐的最短使用流程

1. 先在**资料与来源库**登记有 DOI、原始数据快照、实验记录、模型运行日志或文件路径的资料，标注质量状态。
2. 在**字段与描述符**校准字段口径，在**催化剂样本**导入 CSV；导入的样本统一标记“待治理”。
3. 通过**质量治理**检查原始值、绝/表压、GHSV基准、重复记录、缺失值、来源和工况可比性，冻结训练数据版本。
4. 在**训练与可解释分析**登记真实模型运行，注明分组划分、防数据泄漏、性能指标及适用域。
5. 将真实筛选结果登记到**虚拟筛选**，再建立**候选配方**，按配方和一致测试工况对比。
6. 从已选候选生成**实验批次**（默认保守上限4，可调整为5或6；同时执行的总槽数受限制），录入实验、复核后再登记回灌模型版本和说明。

## 6. 已知限制

- 无自动文献下载、文件解析、数据库同步、AI训练、预测、SHAP计算、自动推荐或实验仪器接口。对应页面是**管理台账**而非执行后端。
- 无服务器数据库、用户登录、授权审计、跨设备实时同步；不得直接当作企业内部多用户生产系统。
- CSV 导入按 `name + sourceId` 等条件做基础疑似去重，不替代真实材料-制备-工况多层去重及单位审核。
- 仅在指定工况字段完全相同才给出“字段一致”提示；真正实验可比性仍需核对反应器、样品、标准化基准和测量口径。**不会自动跨工况换算性能。**
- 默认本地存储未加密，不适合在未经批准的公开托管或共享电脑输入专有配方。
