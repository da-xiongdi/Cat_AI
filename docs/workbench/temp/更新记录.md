- 导航从单层11项调整为四组11个模块，不减少已有功能。
- 总览改为“状态口径 → 研究指标 → 研发链条 → 已知项目记录 → 任务与约束”的决策顺序。

本地页面不具备云端自动同步、真实科研文件接入、模型运行、数据库自动更新、仪器实时接口和多人权限审计。这些未实现能力不是 v1.1 的已验证成果。
