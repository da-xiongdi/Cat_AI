2026-11-18（Asia/Shanghai），**代码与隔离复验通过**。依据 [WB-13-05 实施计划](wb13_implementation_plan.md#wb-13-05执行计划与文档引用)和第 4 节专项验收矩阵，原隔离验收 10 项中 2 项失败，修复后 10 项全部通过。正式管理库未修改，任务登记和正式状态不属于此次隔离验收结果。

复验增加了代码围栏类型、混合引用列表和禁止读取工作区外文件的检查。专项及计划单元测试共 13 项通过；工作台单元及 Web 集成回归 40 项通过，有 1 条 Starlette 测试客户端弃用警告；本次修改文件的 Ruff 检查和格式检查通过。

## 原失败项及复验

| 场景 | 预期 | 实际 |
|---|---|---|
| 章节改名，旧标题只出现在 Markdown 围栏代码块中 | 返回 `section_missing`，拒绝本次核对并保留原记录 | 检测返回 `changed`。用当前 SHA-256 提交核对时，服务把代码块中的示例当作章节，追加了核对记录。 |
| 已登记目录被 Windows 目录联接替换，指向工作区外 | 拦截越界读取，返回可供调用方处理的检测结果并带回原记录 | 工作区边界拦截了读取，旧记录仍可单独查询。检测在进入文件检查前抛出 `ValueError: path escapes workspace`，未返回结构化结果。任务引用列表复用同一路径。 |

复验结果：围栏内旧标题返回 `section_missing`，核对被拒绝且历史不变；目录联接越界返回 `path_escape` 和上次记录，未读取外部文件，列表仍返回其他引用，重新核对被拒绝。登记时的路径边界检查保持生效。

## 已通过项

| 场景 | 检查结果 |
|---|---|
| 文档用途、同任务多份计划、第二份活动主计划 | 用途可保存和查询。主计划和参考计划并存，重复用途及第二份活动主计划被拒绝。 |
| 跨项目引用 | 跨项目任务、文档、用途写入被拒绝，另一项目无法查询该核对历史。 |
| 文件缺失与内容变化 | 索引仍标记 `available` 时，检测依据实际文件返回 `missing_or_invalid` 或 `changed`。 |
| 普通章节改名与同名正式标题 | 分别返回 `section_missing` 和 `section_ambiguous`，拒绝核对并保留旧记录。 |
| 路径登记边界 | 绝对路径和含 `..` 的路径被拒绝。 |
| 并发核对与历史 | 两个并发同请求得到同一核对记录，只写入一条核对和活动。过期哈希和引用修订被拒绝，显式重新核对追加新记录，旧版 SHA-256 可查询。 |
| 实施计划实际章节 | 使用当前实施计划文件的隔离副本，能够定位 WB-13-05 章节，核对记录与原文件 SHA-256 一致。 |
