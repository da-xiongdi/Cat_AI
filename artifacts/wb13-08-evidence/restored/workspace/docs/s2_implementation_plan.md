## 3. 分任务验收

### S2-01：配置与参数

1. 独立于项目Settings，选择数据快照/资格/分区、特征、属性/映射版本、模型、参数、seed、DOI折数和新输出目录；依赖缺失提示先导入/计算。
2. 区分 `baseline_compare` 与 `custom_train`。固定基准锁定三模型、默认参数、3折及R1/R2候选；自定义支持单/多模型，至少2折且不超过训练DOI组数，不回退随机行拆分。
3. 至少支持Ridge alpha、ExtraTrees n_estimators/min_samples_leaf/max_depth/max_features/n_jobs及统一seed，明确类型、范围和并行限制；Dummy仅mean。未知字段、泄漏字段、不支持模型、非法值和重复参数冲突立即拒绝。
4. 提供模型/特征/参数目录、仅校验操作、有效配置及默认/用户值来源；示例通过真实加载器校验，文档不提前声明未实现命令可运行。

### S2-04：特征适配

1. F1=F_base+4项，F2=F_base+10项；复用S1计算器和资格规则，缺席角色保留not_applicable，模型数组按既有规则占位，不把0写为物性事实。
2. 各训练折独立拟合词表和缩放；固定物化计算可复用，不能加载全train词表进入CV。F_cond明确作为工况对照，目标/DOI/样品名不进入特征。
3. 与553条v4固定增量逐值一致；换序、同角色同物种合并及规范预测输入的转换一致。不支持组分不丢弃，不重新归一剩余组分。
4. F1/F2仍受F_base训练词表约束；不改变F_base定义，旧F0/R1路径继续可用。

### S2-05：训练、评价与追溯

1. 默认R1比较F_cond/F_base×三模型；R2比较F_base/F1/F2×三模型，三组特征均在S1共同支持子集重训，同原分区、同折、同算法/参数，禁止与R1全体成绩直接相减。
2. 主指标按所有筛选后OOF记录先算每篇DOI MAE再等权平均；保留未见物种/输出越界的诊断预测并另报入口可用性。模型顺序dummy、extra_trees、ridge；R2精确同分先F_base、F1、F2，再按模型顺序。
3. 仅原train重训最终模型，validation不重新拟合或选模，已查看test标明历史对照；不自动搜索参数，不因误差改支持规则或候选。
4. 报告输入覆盖、全体诊断、入口可用性三层结果及共同可支持子集；保存OOF/留出逐条预测、状态、折归属、有效配置、版本/代码/依赖/参数/哈希，禁止覆盖历史输出。

### S2-06：模型包与预测

1. 绑定输入schema、特征/词表/缩放器、训练记录、属性/映射、资格规则与计算版本/哈希；可保存自定义单模型及F1/F2包，保留旧R1包兼容验证。
2. 加载时校验绑定、文件完整性和依赖兼容；属性/映射/词表替换、篡改或身份冲突须失败；修改参数生成新训练运行和model_id。
3. 单条/批量输入仅需组成和四项工况，不需DOI/性能标签。不支持物种角色或属性/映射返回明确原因，禁止静默切换到R1；批量逐条输出，不删除无效项。
4. 越界工况/组成按现有规则caution，非法或非有限输出不可用；0–100%外的原始输出单独保留、正式预测值null，JSON无NaN/Infinity；重载前后及训练/预测转换结果一致。

### S2-02：入口集成与工程交付

1. Python和配置文件+CLI完成“校验→指定单/多模型训练→保存→加载→单条/批量预测”，默认基准与自定义运行独立编号和目录。
2. 参数目录、帮助、配置示例、预测JSON示例和接口契约与实际实现一致；Web UI不作为交付门槛。
3. 对非法配置、组数不足、篡改绑定、未见正含量物种、零含量项、越界及混合批量输入保留必要回归；R1旧包重放通过。运行全量pytest、Ruff检查与格式检查。
4. 固定代码与测试证据，形成S2工程交付清单并更新进度；工程烟测不能标为S3正式配对比较完成，不以MAE改善作为工程门槛。

### S2-03：家族对照资格

1. 核查标准化家族标签的来源和可信范围，不直接使用由名称派生的195个原始material_family值作为标准分类。
2. 在查看分数前记录资格判据、各家族/分区记录和DOI数；只有可满足既定分区和分组CV条件者进入A统一模型与B1同特征单家族模型对照。
3. 无可靠标签或覆盖不足时明确记录跳过范围及原因；不从样品名强行分类，不阻断统一模型，不提前引入B2专属特征或专家架构。

## S2-04 特征适配接口

`catalyst_ai.features.enhanced.verify_s1_binding(...)` 使用原始快照、资格、分区、属性、映射和来源复核重建并校验 S1 产物；调用方应在选取 S1 共同支持子集之前完成校验。`EnhancedFeatures.fit(fold_payloads, "F1" 或 "F2", properties=..., species=...)` 只拟合当前训练折的 F_base 词表和范围；每折需重新调用。`transform_one` 返回模型数组和包含 `not_applicable` 状态的原始物化描述符。Ridge 等需要缩放的模型应在各训练折内拟合缩放器。训练评估与模型包接入分别属于 S2-05 和 S2-06。

## S2-06 模型包接口

`run_configured` 返回本次训练报告及候选对象；`save_package(path, report, fitted)` 默认保存 OOF 选中候选，也可通过 `candidate=("F2", "ridge")` 指定已训练候选。`load_package(path)` 校验清单、文件、绑定和依赖；`predict_one(package, item)` 与 `predict_batch(package, items)` 共用训练特征变换。只加载可信 pickle 包，原 R1 包接口保持兼容。调用与状态约定见 [API 契约](api_contracts.md#s2-配置化训练与预测)。
